PIXEL DASH - простая пиксельная игра для Nintendo Switch (homebrew, .nro)

Управление: A / B / X / Y / Up - прыжок (держите для более высокого прыжка), + - выход.
Цель: бегите, прыгайте через шипы и ящики (на ящик можно приземляться), собирайте монеты.

Сборка: залейте содержимое папки в репозиторий GitHub - во вкладке Actions
появится артефакт pixeldash-nro (внутри pixeldash.nro).
Установка: скопируйте pixeldash.nro на SD-карту в /switch/ и запустите через Homebrew Menu.
